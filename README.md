# ☕ Coffee Shop Website

Bu proje, bir kahve dükkanının tanıtımı için hazırlanmış **modern ve responsive bir web sitesi** çalışmasıdır.  
Proje kapsamında ana sayfa (Home), hakkında (About), menü (Menu), kullanıcı yorumları (Testimonials), galeri (Gallery) ve iletişim (Contact) bölümleri bulunmaktadır.

Projenin temel amacı, **HTML, CSS ve JavaScript bilgilerini pekiştirmek** ve gerçek hayata yakın bir front-end uygulaması geliştirmektir.

## 🎯 Proje Hakkında

- Kahvelerin ve ürünlerin tanıtıldığı bir **menü bölümü**
- Kullanıcı yorumlarının yer aldığı **testimonial slider**
- Kahve dükkanı hakkında bilgiler içeren **about bölümü**
- Kullanıcıların iletişime geçebileceği **contact form**
- Tek sayfa (landing page) mantığında, bölümlere ayrılmış yapı

---

## 🛠️ Kullanılan Teknolojiler

- **HTML5**
- **CSS3**
  - Flexbox
  - CSS Grid
  - Responsive tasarım
  - Animasyonlar ve hover efektleri
- **JavaScript**

  - Scroll’a bağlı aktif menü takibi
